第16案例 班级成绩报告增强版
========================================

一、先看这里
本项目在原课堂案例“按班级计算平均分”的基础上扩展，仅用Python标准库。
支持Python 3.10及以上，无需安装pandas、matplotlib或其他第三方包。
演示数据全部为虚构课堂数据，请勿当作真实学生成绩。

最快体验：直接打开“示例报告/班级成绩报告.html”，无须运行Python。
Windows运行：双击“运行演示.bat”，重新计算报告并打开浏览器。
Notebook学习：打开“Python基础课堂代码练习_案例16增强版.ipynb”，按顺序执行第16节。
成绩管理：双击“成绩管理.bat”，支持查询、新增、改分、删除、导入、生成报告。
Jupyter本身需使用你的已有环境；运行独立.py与阅读报告不需要安装Jupyter。

三、新增功能
1. 多班级、多科目、多次考试，考试之间分别统计，不混作同一次考试。
2. 班级/科目均分、中位数、最高分、最低分、总体标准差、及格率、优秀率、分数段。
3. 学生有效总分、科目加权均分、班内综合名次、缺考及待补录科目、不及格提醒。
4. 同分并列名次1、2、2、4；科目不完整者展示已考均分，但不参加综合排名。
5. 相邻考试进步值：按考试名称排序，只有同一学生、科目集合一致且成绩完整才比较。
6. 查询、新增、修改、删除、CSV/JSON批量导入与JSON持久保存。
7. HTML离线报告：班级均分条形图、分数段、班级和科目表、学生搜索与筛选、打印。
8. 有效成绩、班级统计、科目统计、个人统计、数据问题分别导出CSV；完整结果保存JSON。
9. 非法成绩、缺字段、重复成绩、姓名冲突进入问题清单；严格模式拒绝有问题的数据。
10. 原report(records)用法保留，不修改传入的列表、字典；报告与原始输入分开保存。

四、命令行示例
先在终端进入本项目目录。
运行演示：
  python class_report.py demo
交互式管理：
  python class_report.py menu
指定管理数据文件：
  python class_report.py menu --data 我的成绩.json
从CSV生成报告：
  python class_report.py report --input examples/示例成绩.csv --out 我的报告
中文表头：
  python class_report.py report --input examples/中文表头模板.csv --out 中文模板报告
自定义阈值及权重：
  python class_report.py report --input examples/示例成绩.csv --out 加权报告 --pass-line 65 --excellent-line 85 --weights-file examples/科目权重示例.json
查看容错诊断：
  python class_report.py report --input examples/异常数据示例.csv --out 异常检查
严格模式（发现任何问题时返回非零退出码，且不生成或覆盖报告）：
  python class_report.py report --input examples/异常数据示例.csv --out 严格检查 --strict
运行测试：
  python -m unittest discover -s tests -v
查看帮助：
  python class_report.py --help

五、CSV和JSON数据规则
推荐字段：student_id（学号）、name（姓名）、class（班级）、exam（考试）、subject（科目）、score（成绩）。
也支持中文表头：学号、姓名、班级、考试、科目、成绩。
CSV用UTF-8或UTF-8 BOM编码，逗号分隔；可用examples中的模板填写。
学号按文字保存，保留前导0；同名学生使用不同学号即可。
支持最简旧格式class、score；缺省学号按行生成，考试默认为“默认考试”，科目默认为“综合成绩”。
正式数据请始终提供稳定学号、姓名、科目和考试，避免合并多份无学号文件。
分数范围为0—100，允许小数；None、空白、缺考、未录入、NA、N/A、--表示缺考。
0分是有效成绩；负数、超过100、NaN、无穷大、布尔值均拒绝。
同班级+考试+学号+科目是唯一键；相同键再次出现视为重复，不会静默覆盖原成绩。
同一班级同一学号的姓名需一致。修改成绩请使用管理菜单，而不是插入重复记录。
JSON可为记录列表，也可为含records列表的对象。
菜单导入为“追加”：任何问题都会使整个追加取消，原数据保留。
报告默认“容错”：跳过有问题的记录，保留首条重复记录，并输出具体行号及原因。
CSV数据问题行号从第一条数据记为1，不包括表头；不是Excel界面中的物理行号。

六、统计口径
平均分、中位数、总体标准差、最高/最低分只使用有效成绩，缺考不按0分计入。
及格率=达到及格线的有效成绩数/有效成绩数；优秀率同理；无有效成绩时显示“—”。
分数段固定为[90,100]、[80,90)、[70,80)、[60,70)、[0,60)，自定义阈值不会改变分段。
班级均分是同班同次考试所有有效单科成绩的算术平均，不是个人综合均分的平均。
全体概览与分数段合并全部考试，用于整体数据检查；正式比较应查看分考试的表格。
个人有效总分是已录入有效科目之和；加权均分=Σ(成绩×科目权重)/Σ(有效科目权重)。
未配置权重的科目使用1；权重必须是有限正数，每科满分均为100，不支持混合满分制。
只有本班本次考试所有已识别科目均有有效成绩的学生才参加综合排名。
并列以加权均分保留8位小数比较；显示保留2位小数，显示相同不一定代表内部值相同。
本班本次有人提供某科目而某学生无该记录，识别为“待补录”；明确空分则为“缺考”。
如果全班完全未提供某科目，程序无法知道应考该科；请事先补上该科的空成绩行。
班级表、科目表同时展示有效/缺考/未录入数量；出勤率以已提供记录数为分母。
考试建议使用01_期中、02_期末等有顺序前缀的名称；进步值是加权均分差，不是总分差。
HTML中的筛选只作用于个人表，其他表保持全量；打印保留个人表当前筛选。

七、数据保存与操作边界
管理菜单默认把数据保存到程序同目录的“成绩数据.json”。
改分时使用班级、考试、学号、科目定位；删除需输入YES确认，只删除一条科目成绩。
JSON先写临时文件再原子替换；写入失败保留原文件，菜单也回滚本次内存修改。
请勿多开管理窗口同时编辑同一数据文件，本项目是单人课堂应用，不包含数据库并发控制。
报告生成会更新目标报告目录中的固定文件名，请为不同数据集使用不同--out目录。
程序会阻止本次输入文件被同名报告覆盖，但不会为历史报告创建自动备份。
CSV导出对以=、+、-、@起始的文字前置单引号，避免表格软件当作公式；此类文字往返导入可能保留该单引号。
HTML对姓名、学号等内容进行转义，不会把输入当作网页代码执行；报告不连接网络或上传成绩。
Python源码导入不会自动运行；main入口与Notebook演示分开，Notebook执行不会弹出输入菜单。

八、与课堂知识的对应
列表和字典：存储成绩；setdefault/defaultdict：按班、科目、学生分组；集合：比较科目。
函数：清洗、统计、导出分离；lambda与多关键字排序：成绩排序；对象：GradeBook增删改查。
异常：明确处理无效输入与文件错误；main：组织命令入口；标准库：csv/json/statistics/pathlib/unittest。
建议先看report、normalize_records、summarize，再读analyze与GradeBook，最后阅读HTML导出代码。
