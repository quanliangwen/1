## 源码定位

`source/be_ro_solver.cpp`是单一BE-MISOCP模板，`source/be_ro_witness.hpp`是有理数与208-bit支持函数见证，`source/be_ro_search.cpp`是B1流程。`be_reader.py`独立重建KKT见证，`audit_reader.py`核所有终末记录、源/输入、原LSS及原整数CDF证书。旧共有代码未在磁盘删除，但B1分支不调用R07四阶段机制。

编译需要外部适用Gurobi SDK/许可证、GMP与BLAS，源码包不包含SDK、许可证或原始benchmark数据。全量实际源/input pins以本交付PROTOCOL.json为准，source中旧版本CHECKSUMS等仅为继承来源快照。
