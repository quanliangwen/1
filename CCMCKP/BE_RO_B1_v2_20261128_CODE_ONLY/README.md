## 已实现的增量

1. `source/be_ro_linear.hpp`：原始样本的μ/方差/尾部偏差仍由原 `BEROWitness` 计算；新增固定λ的Huber系数、有理数线性行、向外舍入和零半径/盒角端点。正半径使用10点自适应几何网格，资源探测使用12点。
2. `source/be_ro_linear.cpp`：每个子问题只有n个二元变量、一组一项等式及一条资源线性约束；单线程、1秒（包含建模）、目标gap设为0，单解或10解池。0%是求解目标，不是对限时返回状态的承诺。逐条复核实际舍入行与有理数行，不接受求解器容差导致的违规向量。
3. `source/be_ro_search.cpp`：12步无MIP资源探测；只按本轮最便宜#1候选的私人FFT定位半径；二分与解池阶段的全部KKT通过候选进入 `CandArchive`；扩展四个非对称临界点及可行盒角；统一按成本进行原CDF认证、动态第5成本截断；不足5解时最多3轮向上兜底。空认证池允许前10个未尝试候选按FFT降序送原CDF，首解接受后转为0.985私人门槛和成本排序。
4. `source/CMakeLists.txt`：主程序链接新线性求解器；旧锥模型源码仅留作历史来源/旧tiny目标，不在B1-v2主流程调用。新增tiny目标默认关闭。
5. `linear_reader.py`：准备了独立Fraction读者，核线性行、原KKT见证、归档来源、认证池与时钟。它尚未执行，不能替代未来的源/input冻结审核、原整数CDF证书核算和最终LSS记录审计。
6. `source/tests/be_ro_linear_test.cpp`：准备了固定行枚举对照、Huber恒等式、零方差/零偏差/零半径与盒角tiny检查，**本次未编译或执行**。

## 对设计文档中数学和性能表述的落实

连续λ的对偶表达是支持函数恒等式；完整表达需用infimum并处理λ=0盒角、λ→∞/Ω=0端点。**有限10点网格不是原BE模型的完整等价求解器**。固定λ行提供保守充分条件；全网格无解或1秒无候选不等于原BE不可行。记录已显式设置 `finite_lambda_grid_is_exact_optimizer=false`。

12步有限网格探测只得到找到可行见证的搜索半径，不能称为“精确可行半径上限”；零值可能只是尚未找到正半径的哨兵值。FFT随最便宜候选的变化也没有单调性保证，所以Ω*是启发式定位值。所有已生成候选仍保留，降低误切造成的损失，但不能保证彻底消除退化。

文档中的“0.02–0.2秒收敛”“消灭155次失败”“消灭空池失败”是待验证目标。文档所述服务器原型成绩没有在本次重复或独立核验，也不作为本交付的实测结果。固定参数β=.95、K=5和其余工程常数均按设计保留，不据历史解构造候选。

四点均裁剪到[0,本次搜索半径]，处理半径小于.05或为0的退化情形。CDF通过造成epsilon扩大时，可重新考虑先前较便宜的私人FFT拒绝候选；已经尝试原CDF的向量（包括unknown）绝不补跑。兜底可重新考虑整个归档中的未尝试候选，仍不读取外部结果。
