## B2操作与限制

K=5是公有认证池前5个不同选择向量，k=5是最多改动5个组，对应最多10个0/1位变化。LB每轮2秒、解池20、单一风险行/距离行/动态成本/NG，真正最好成本下降才重置stall，两轮不改善或无返回向量就停止。原整数CDF仍是内部入池认证，原LSS统一终审。

第一阶段若没有自身认证起点，则B2不做局部支化，记录失败，不借旧解兜底。第二阶段模型没有文档之外的BE半径约束，LB解不冒称通过第一阶段某Omega的鲁棒见证；它是RO引导的matheuristic，不是全程同一DRO保证。有限时零候选也不证明邻域或原问题不可行。详见B2_实现与执行边界说明.md。
