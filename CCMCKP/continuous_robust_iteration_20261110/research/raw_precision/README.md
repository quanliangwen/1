# 概率计算精度与未决候选诊断

这项研究读取已冻结的12个开发/工程输出，不是新的独立冷启动求解器。以已公开合格成本标量筛出7个有竞争力的未决候选；这项外部筛选明确使用了历史信息，所得点不能注入新求解器或计作30次Avg改善。

现有S10 native_check在剩余时间不足45秒时跳过262144及更细网格；达到最高1048576格仍不能判定时，把已算过的整数区间丢弃并存为lower=0的unresolved，再次访问同一向量也直接返回。未决不是已被整数证书证明不可行。旧记录缺少区间，因此不能据其推断概率精度没有影响。

新独立上下界计数器先通过50模型600项Fraction完整枚举及嵌套网格检查。随后7个旧候选在2097152格全部判定，193.096秒：4个整数下界≥0.99、3个整数上界<0.99。四个原样本合格点成本分别为39号323.709973966731、324.952688537639、325.058651360977和40号291.834622618568；后一成本低于历史291.936219，但不代表它通过原LSS。

第二实现独立重算全部4份下界整数、原输入身份、组约束和成本，56.550秒通过。另做12次更粗网格的下界计算，34.869秒：39号324.952689与325.058651在262144格已可证明，单次约1.5秒；39号323.709974及40号291.834623在1048576格仍不能证明，需要2097152格。两点的原先遗漏可能来自末段预算门槛，另两点需要更细精度。这是计算耗时诊断，不是受控求解器速度对照。

既有缓存核对显示四点原LSS身份全部未知。原real_P_test（1000万、种子832273、sum≤T、点估计≥0.985）已实际排队，等待正式F001验收结束；结果另存，不把未知当作成功或失败。当前冻结I002/F001、I012和I014均未被这项研究修改；没有新增概率硬筛、门槛放宽或真实参数反馈。

下一步假设：在新的源版本中保存自己搜索产生的未决区间、允许按时间预算重试，并依据本机实测整数计数耗时安排精化。必须先验证边界/预算/不重复计数，保持同一600秒总预算和全部既有合格候选；任何新收益仍需成本顺序原LSS及新种子复核。不能仅凭这四个外部点承诺Avg改善。
