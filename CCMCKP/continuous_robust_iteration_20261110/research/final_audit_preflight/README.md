固定联合验收是：全部原始边缘样本独立组合的严格sum<T概率≥0.99，且原real_P_test用1000万次、seed832273、sum≤T所得点估计≥0.985。原Best的样本概率都达到0.99，但原LSS点估计都不够。

覆盖125+125+625=875个选择组合，精确复核全部328个低于联合可行见证成本的组合。289个因原样本概率不足0.99被排除，39个虽过原样本条件却被原LSS拒绝；原LSS未知0，更便宜联合可行0。三项最优见证均通过双门槛。

第一套程序使用Fraction十进制有理数折半计数；第二套程序独立把十进制系数/指数缩放成整数，再做整数折半计数，不导入优化器或第一套原样本验证模块。第二套逐项重算全部328个便宜选择的精确概率和成本，复核全空间覆盖及42项原LSS完整身份/源码/数据/环境凭证。没有新增MC调用。

因此这三例在当前固定联合验收下，任何30次均可行结果的Avg都不可能降到原统计表Best。联合最优成本分别为14.076616、13.564858、5.796148。结论只适用这三例及该固定验收谓词，不外推其他例、总体概率或完整DRO歧义集合。其余例仍继续优化；40×30正式实验不删除这三例。

SMALL_FORMAL_COMPATIBILITY.json是已冻结正式队列每个16小例的单个真实搜索种子9707001与既有原LSS凭证的只读诊断，未向正式validation目录写后选择记录，未产生30次Avg。first3_APP_oldBest_compatible=false准确表示旧成本与当前联合可行最优不兼容，不是源码或审计完整性失败。
