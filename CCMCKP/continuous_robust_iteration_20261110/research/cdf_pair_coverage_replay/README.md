# 通用两组覆盖：旧自身CDF池上的实际回放

D002证明I014新合格点324.916225来自四组扫描，但实际仅改变中心的两组。这提示随机四/六组掩码可能造成复现波动。下一步可用通用全部组对覆盖检验这一机制，不把已知组编号或向量写入算法。

本研究只是外部事后回放：使用I015已经冻结的自身176个CDF成员，运行原有、未改数值内核的RobustPairs，遍历通用组对/中心/风险层，未把D002见证加入初始池或工作排序。给单独120秒回放阶段，并以原base+CDF时间模拟原全局剩余时钟。实际108.100634秒，27个中心/风险层扫描全部完成，共33075个组对，三种CDF扰动0/0.00025/0.0005均执行；池176→1065，新增889个原样本合格候选，全部初始成员保留。

该通用过程自然再现了先前验证通过的324.916225向量；这次来自delta=0.00025的候选排序。新证书独立整数重算通过，原LSS0.9854033凭证来自先前D002同一身份的实际调用，没有新增原LSS仿真。并未再现另一种子I015的325.659438向量；两组覆盖与更大随机邻域并非同一候选集合。

这不是新冷启动成绩或新稳定性结果。旧CDF池是保存的历史向量，重建决策只含保存的CDF拒绝项，未保存的原base拒绝项没有重建；初始化和工作量可与新生产搜索不同。也没有验收整个1065池的原LSS成本前缀，不能宣称回放最低合格成本已经确定。只确认已知合格见证能被通用覆盖再现。

若新种子揭示随机块的波动，将另存新版本：保留自己CDF池，优先通用鲁棒组对覆盖，再用剩余预算做块邻域及精度收尾。所有阶段共享600/180秒，最终原样本99/原LSS985不变，不新增尾部硬筛。必须另做源码/数值/调度检查、全新种子冷启动、全候选独立重算与完整成本前缀，然后新种子及全40×30。本回放不能替代这些生产证据。
