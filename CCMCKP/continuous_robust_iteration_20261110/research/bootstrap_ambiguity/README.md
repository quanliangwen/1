# 有限重抽样联合模型的鲁棒CDF提案原型

状态：原型与数学检查，未接入任何求解器、未产生新的独立冷启动或原LSS仿真。它不是新的概率硬筛，也不是原始DRO歧义集合或总体概率置信保证。

构造以原样本整数频数表示的名义网格边际和4个独立均匀重抽样版本。每个模型是全部因子边际的乘积分布；歧义集合为这些**联合分布**的凸包。事件概率对联合混合权重线性，所以最差CDF等于各模型CDF的最小值；这不同于先混合各边际再取乘积。网格之外的质量保留为显式overflow类别，不把尾部重新归一化掉。

471项计数/概率检查包括42个中心卷积、252个单组替换导数、105个完整联合混合、72个名义频数对照，另有7种无效输入检查；确定性重抽样、尾部质量和联合/边际混合区别均通过。独立完整正系数卷积最大绝对差5.55e-17。多组同时变化仍仅是线性化提案，不把它当作可行性证明，最终原样本整数99及原LSS985仍必须另验。

在六个已经知道真值标签的旧正负对照上做了明确事后诊断，模型只用原样本，分数全部算完才合并标签。模型构造约0.097秒、总分数诊断约0.609秒、数组40.96MB；这些是原型开销，不是求解器性能。名义与最差模型分数均将已知正例排在负例之前，但名义分数本身已能如此，不能据此断言重抽样模型带来增益；某些失败点的最差模型分数仍高于0.985，更说明它不能替代原LSS验收。

完整前缀已发现原有CDF+块方法的实质联合降本，当前优先做新种子稳定性复核，并研究两组邻域通用覆盖以降低随机波动。该原型暂存为备选候选生成方向，不因对照分数而启动新的40×30或增加尾部硬筛。
