# I007：精确成本-CDF上界，新增剪枝已复核

思路：把剩余成本和重量容量联合放入动态规划。成本、重量使用Fraction向下量化；允许后续组的选项随已观察重量调整，是固定选择问题的放松；每次整数卷积除以样本量时向上取整，再逐状态取最大值。因此得到的是原问题概率的乐观上界。低于0.99才排除对应成本/前缀集合，不作为可行性下界。

完整原始经验样本、严格事件sum<T和0.99不变。原LSS real_P_test固定种子832273、10m、sum≤T点估计≥0.985仍在搜索外验收。这轮没有新增真实概率调用，没有新增尾部硬筛。

验证：12个小模型、384次递推，共26112项检查；既枚举全部固定选择和所有联合样本结果，又用独立逐观测Fraction递推核对每个成本/容量状态，覆盖两种组顺序、固定前缀、成本无解、零剩余成本、不同样本长度和向上舍入误差。

编号35，旧成本线193.774222960923，固定前缀[30,121]，512个重量格、256个成本格、Q=2^48。主程序11.076秒完成，整数上界276451293220031/281474976710656≈0.9821522909448923。独立程序22.503秒重算30张中间表和40153项整数卷积，逐张SHA一致；原CDF包络的精确上界约0.993169881432608。因此这是确实新增的安全剪枝，仅排除该前缀子树，不能据此排除整个编号35，更不是新的LSS合格降本。
