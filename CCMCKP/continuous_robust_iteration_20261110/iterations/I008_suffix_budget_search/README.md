# I008：将精确上界保存为后缀表

I007每个前缀重新计算整张DP表成本较高，因此一次预计算每个剩余组后缀的整数成本/容量上界。搜索到固定前缀后，用其精确已付成本计算剩余成本格；再把前缀原始重量概率与对应后缀表组合。原0.99约束保持不变，只有经过整数上界证明不满足它的分支才剪掉。

验证：12个完整小模型、24次整树试验，41989项检查通过，包括每个剪枝子树的全部原始联合样本、精确成本、可行/不可行/未决叶子、前缀分区，以及独立Fraction递推的每个后缀表状态。另4个确定性边界模型验证零成本、成本无解、零剩余增量预算和预计算超时不会误排除。最初检查器忽略“未决允许存在”的设计，在容量边界质量的例子上断言失败；生产源码未因此更改，失败输入/树在math01，原因和测试修正见MATH_ATTEMPT01.json，完整复验在math02。

编号35旧成本线193.774222960923，512格重量/256格成本、48位概率，120秒工程预算：118.001秒预算退出；DP12.423秒，访问163979节点，145941项新上界剪枝、409个原样本不合格叶子、1228项成本剪枝，无原样本可行叶子、无未决叶子。覆盖约99.5878%的10^30组合，仍余约0.4122%，不能作全局排除，不能把体积比例当剩余时间。

独立审计139.091秒重算30张DP表、44326项DP整数卷积、146350项树证书，并重核所有前缀的精确成本和完整空间划分。其程序不导入优化器，用排序阈值构造经验质量和CDF差分重建矩阵。所有原始输入与登记SHA匹配。

这轮没有新LSS调用或新的合格降本，不替换正式I002。真正的40×30仍由F001冻结版本执行。后续核计算诊断在1000个确定性抽样自有证明节点上，3种公式各3次、共9000项整数值完全一致；CDF增量乘积的本次内核计时较低，但不是受控的整机算法速度结论，记录见UPPER_KERNEL_DIAGNOSTIC.json。
