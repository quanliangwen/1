# CCMCKP 严格经验概率验收与稳定性优化 S2R2

本版优先修复概率低于 0.99 的问题：最终接受完全改为整数计数，不再依赖蒙特卡洛观测，不再使用浮点保护量作最终验收；同时修正旧 MC 分支遗漏每个边际最后一个样本的问题，使用全部原始样本。

## 可行性凭证

将每个原始十进制样本精确解析为有理数。对于网格 B，把每个资源值向上取整为 `ceil(B*a/T)`，对各边际的整数计数多项式相乘，取总次数小于 B 的系数之和 N。分母 D 是各边际样本数的乘积。因为向上取整后的和小于 T 必然意味着原始和小于 T，`N/D` 是原始经验成功概率的下界。

程序只在 **`100*N >= 99*D`** 时接受候选，运算和比较均为任意精度整数；输出保留 N、D、网格、输入哈希，并在计时结束前重新计算凭证。浮点 CDF 和 DRO 排序只用于候选筛选，不能绕过整数接受条件。底层整数多项式使用 [FLINT 的 fmpz_poly](https://python-flint.readthedocs.io/en/latest/fmpz_poly.html)。

这个保证针对“原始十进制边际样本等权、各组资源独立”的有限经验分布，不等同于未知总体概率或所有歧义分布上的概率保证。原 CDF 歧义构造仍参与候选引导。

## 搜索

小规模至多 100,000 个组合的算例按成本顺序枚举，对更便宜组合使用整数概率上界排除，首个通过整数下界验收的解可附枚举最优性记录。其余算例使用已认证初始解、多均值/方差候选、CDF 局部模型、单/双组交换、折半 CDF/DRO 搜索和不同种子的额外分组。每次独立启动，不读取历史或其他运行的解。
