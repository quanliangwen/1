## 代码审查、机制与文献依据

基线：每组一项，原总成本最小化与容量/原生门槛不变。原初始化先以均值+3倍样本std为代理目标，用Gurobi构造最多8个池解（3秒），第一个原生通过者为本run起点；不用历史解。CDF扰动把低端最多δ质量移向观测最大支撑，上取整4096格并卷积评分。评分.975筛候选，原60000抽样预筛.975、原生M1000000/.99决定接纳；原精确/MC、末样本索引、快速拒绝、正结果复用及RNG推进方式均保留。

原搜索用成本分层的有限半区束（512成本桶），在三种分区和三个原半径的九个阶段槽位间联动，再MITM分块拼接；有限束宽、top候选、降本档与检查上限会舍弃解，不能声称完整枚举或全局最优。FFT、子状态PDF拼接/复制、原生排序快拒绝和百万MC是主要计算/内存开销；MC近门槛的接受差异及墙钟内完成阶段数会改变自适应搜索轨迹。

R04唯一实质算子是在原初始化后加入一个成本MILP提案阶段，再继续原九阶段CDF/MITM。沿用原robust_logmgf、THETA网格及δ=.00025。若独立有限支撑边际为Y_j，ψ_j(θ)=log E exp(θY_j/T)，则

`P(ΣY_j≥T) ≤ exp(Σψ_j(θ)−θ)`；所以固定θ时以二进制每组选一项约束 `Σψ_j(θ)x_j−θ≤log(.01)` 为保守充分条件。辅助MILP以原成本为目标，用指标变量表达有限θ并集，归一化行保留1e-10余量并按原系数回读核验。最多8个不同提案、20秒软阶段；第一个原生接受的严格降本提案即结束。结构上半区状态总数不超过原束宽时跳过。

**新旧模型关系：** 没有缩小δ、降低门槛或替换主问题。有限θ的指数界提案集合更保守，只生成候选；所有提案仍需原CDF及原生评价通过。有限支撑、独立性和可计算MGF是公式适用前提；二进制域不继承连续凸规划可解性。原扰动半径未校准统计覆盖，观测最大值不是未知总体上界，浮点计算也不是有向舍入证书；不声称严格未知真分布DRO覆盖或原问题全局最优。
