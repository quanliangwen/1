## 验收未通过的原因

成本终点指标满足原最终要求：整体下降、改善例数大于退化例数、16小/12中/12大三组均不劣。39和40例的成本退化不单独构成最终成本条件失败；最终条件允许退化例存在，只要求改善多于退化。

未通过的是独立的真实学习活动要求：每seed真实更新、反馈决策与非默认动作均须大于0，且每例模型分数影响最终选择、总原子接受数大于0。实际未达标例号及seed数为 {35: 5, 37: 6, 39: 24, 40: 2}，缺失字段计数为 {'feedback_decisions': 37, 'nondefault': 26, 'updates': 15}。完整逐seed清单见 [U18_learning_activity_failures.csv](U18_learning_activity_failures.csv)。

完整选择事件与私有Beta/epsilon/mixture RNG从各seed中性模型独立重放，累计gain/time和最近256窗淘汰也逐条重算。重构正确与活动门槛通过是两个结论：本次没有通过删除断言、修改热身或放宽门槛把负结果改成通过。
部分seed在600秒原预算内没有进入后验反馈决策或非默认动作。保存的事件能定位缺失活动，不能仅据此把端点成本变化归因于窗口算法或机器负载，也不能按负载重跑有效阶段。
