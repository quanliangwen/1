# 第29—32页蓝白样图

四张 PNG 沿用蓝白北邮模板，分辨率为 1448×1086。ZIP 内含四张样图。

- 第29页区分幻觉、过时信息、上下文缺失和工具失败。引用及其报销期限是明确标注的虚构错误示例。320 元乘以 3 晚的正确结果为 960 元。
- 第30至32页沿用虚构的差旅报销制度。v1 规定返程后 5 个工作日内提交，v2 自 2026 年 9 月 1 日生效，规定返程后 10 个工作日内提交。第30页使用办公场景照片，照片中的人员与该案例无关。
- 第31页的二维点位由教学设计确定，未运行嵌入模型。检索候选须结合日期、权限和来源筛选。
- 第32页保留 Lewis 等人 RAG 论文的图1，双流程为教学设计。回答所引的文件、版本和条款与第30页的虚构制度一致。
