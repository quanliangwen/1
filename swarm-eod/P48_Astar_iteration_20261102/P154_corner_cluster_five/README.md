## 本次规则

- 每次先算原布局，再尝试至少60%的可重排弹药进入一个有实测双墙跨度支持的角落，满库存目标6/10。
- 集中区半径2倍爆炸半径R，仍保持原合法规划间距、实际SDK24px物理规则、禁区、库存和路线预算。不是完全重叠同点。
- 新方案必须保留同次原方案至少90%的条件剩余已知墙面覆盖估值，且数量完整、集中程度确实增加；否则回原方案。这不是实际官方墙体分90%的保证，后续看真实分数。
- 原机会成本模型没有“集中”目标，因此只对匹配当前已接受计划签名、时间和覆盖保护的圈内目标，保留新的布局意图；其他任务/合法性/路线拒绝/预算结束仍原判断。
- 计算有界，原A*运动、地图/感知、开始探索与退出规则、依赖、SDK、蓝队、线程和时限不改，没有P153阶段/P145地图过滤叠加。
