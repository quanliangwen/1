## 结果判断

Map08的两个局部修复已生效：1号改选新图，普通同帧双提交消除。但尚未解决“由持有更好地图者先结束比赛”：本局仍是0号在3448步交图，1号未轮到自己的提交窗口。

Map08可确认的记录：

- 0、1、3、4号都在3444步重画并选中各自当前图。1号最佳槽5、版本3444，原F1为0.9498144536；不再选择F1更高但较旧的3274步槽6。
- 1号当前图SHA256为a2b13dd8af95eb2165a021c903a0885ec0abd73641c09739deed482d008169c4，与上一版三图候选实际提交的77.1892分位图逐像素一致。
- 本局只有0号实际调用提交：3446步提出提案、租约到3450步，3448步提交3444版槽5。没有0/1号同帧双提交。SDK采用的就是这一份0号图，地图分73.2007。
- 1号时隙为3450～3455步，但比赛在3448步结束。因此“1号已选对图”并不意味着它实际有机会提交。
- 0号结束时没有1号竞价条目，也没有与1号的同期更高竞价比较记录；它收到的3号3446步竞价为2943，与本机同一步竞价相同，因此原规则无需让行。0号没有进入让行等待，priority_audit和wait_started均为null。
- 1号/4号小组收到的同期竞价为4546，但没有送到0号。原竞价恢复的是基于实际收到消息的比较，无法自行跨越通信分区；编号时间槽解决互斥，没有证明全局地图最优。
- 相对180＋24候选，小计只增加0.1907，地图分增加0.3813，漏墙减少1043像素，扣分误画增加6460像素；探索率、10枚实投和16点掉血不变。
- 相对上一版三图候选，小计仍低2.0048、地图分低3.9885。新增留时/互斥尚未恢复原来由1号提交的地图收益。
- 与180＋24候选的3447帧机体/炸弹录制状态逐项完全一致。该局分差来自最终选中位图变化，不能归因于扫描路线、投放或探索过程变好。

Map09可确认的记录：

- 0号4778步交图，墙钟178.6015秒，小计43.0876、地图分66.0303。0～4号均在4778步执行walltime硬兜底，SDK仍采用0号图。四个版本的Map09均存在五机同帧硬兜底；这是本次明确保留的最后交图路径，不是普通6步时间槽失效。
- 所有无人机都没有进入ordinary_selection模式，没有最终重比或普通分组提交。1号因此未触发普通交图的0.003偏新规则；其最后实投确认在4344步。
- 0号结束时仍只知道1号2832步库存1、3号2804步库存1，没有收到它们的末弹清零确认，所以普通交图继续被实际投放确认挡住。
- 0号采用4590版当前缓存，提交位图SHA256为082dc9e2f5f479fdb343c7da0feea0b9f3dea2f56c26d22d155e769efea17807，与180＋24候选实际提交图完全相同。地图分、漏墙31264、误画63036、墙覆盖42.1346、探索率92.0221%、10枚实投、总掉血5均相同。
- 相对180＋24候选，多运行115步、小计少0.3042；该差值全部来自时间项，墙钟仅差约0.004秒，不能认定为新增115步主动等待或稳定计算变慢。
- 相对上一版三图候选，小计高0.2296、地图分低1.0550；相对原版小计高5.6286、地图分高8.9423。既有Map09地图收益保留，但普通提前交图仍未实现。

本轮未修改算法，也未继续追加测试。暂不建议以本版替换上一版三图候选：本机近分选图和普通互斥已生效，但Map08仍未由持有更好地图的飞机提交；Map09保住已有地图收益，普通提前交图没有实现。不把单种子墙钟触发步数变化当作计算提速。

## 文件与限制

CANDIDATE_SOURCE.zip为上轮冻结研究候选的原字节快照，未上传官网、不是新正式参赛发布包。两份RUN_EVIDENCE.zip保留比赛评分、轨迹、位图、证据快照、三版历史对照证据、源码/SDK绑定与运行采集脚本。ANALYSIS.json额外记录同帧提交、1号选图、最终竞价状态与位图哈希；HARNESS.zip包含所有本轮采集分析脚本。

每图仅1局，三个对照是历史同种子运行；墙钟负载差异会改变墙钟兜底时的步数，不能直接称为算法加速。普通时隙只限制普通出口；硬兜底允许多机同帧提交，以保留既有最后交图能力。
