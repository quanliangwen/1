# V16 拟合按行索引：等价验证与离线耗时

**结论：三图离线估算均达到1秒门槛，保留为研究候选；正式比赛基线仍为V16。** 没有运行或排队整场仿真，没有生成正式比赛新版本。按真实调用次数折算的收益是离线估计，不能写成已实测比赛省时。

## 唯一算法修改

从正式V16开始，仅修改line_regularization.py的regularized_walls()。其他55个文件逐字节相同，包括导航、投放、1.5秒墙钟预留及地图生成的所有调用时机。没有叠加此前方向函数、评分和解包优化。

np.nonzero()产生按行排列的墙点后，建立每行起止位置表。每条霍夫候选线先按原矩形的y范围定位一个保守的连续点区间，仍执行原来的四个比较条件，并将局部编号加回原全局偏移。保留原点顺序、原delta/@运算及全部拟合公式、阈值、候选线顺序、边界处理和画线顺序。非有限范围回退全点比较；缓存命中和无候选线的原早退路径不变。

106组输入全部通过，包括强制提供候选线的随机反例、水平/垂直/斜线及端点反向、首尾行、空行间隔、越界线、零长度线、无候选线、无墙点、单行、非连续/Fortran数组、分数/负数/非有限fit_band、原拟合缓存命中与输入/参数变化、真实霍夫输出和已有快照。

测试直接加载实际V16/候选归档中的函数源码。未修改原函数来插入记录语句；通过外部追踪及OpenCV调用观察，逐条比较：

计数校正：前次只读诊断曾把多行表达式反复触发的行事件数当作候选线查询数。该数字不准确；本次在筛选完成后计数，以上是真正逐条比较的记录数。此前依据行事件累计的“约4000～4800条候选线”不应继续引用。此处不以旧事件次数推算收益。
