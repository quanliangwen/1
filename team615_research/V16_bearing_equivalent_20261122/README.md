# V16 两个方向证据函数的等价加速

只优化 `bearing_core.py` 的 `hit_direction_bits()` 和 `independent_incidence()`。V16其余55个文件逐字节不变，`MIN_WALL_MARGIN`保留1.5秒。未运行比赛、地图构造或物理步进；未恢复此前暂停的低负载整场测试队列。

## 实现

- 激光方向归并：用命中格子的有序唯一编号建立小数组，再按原规则按位或；保留非零筛选、升序编号、int32/uint8类型和边界/无效输入处理。
- 方向组合判断：按原方向间隔规则预计算256项只读布尔表，查询结果保留原形状、布尔类型和标量输入对应的零维数组返回。
- 只读查表在模块导入时建立，没有地图、导航、布弹判据、拟合参数、通信或交图时机规则改动。详细补丁见 CHANGES.patch。

## 等价验证

2958项检查全部通过：穷举256种组合（向量、矩阵及每个标量），2500组固定种子的随机激光反例，重复命中及同格不同扇区、0/2π交界、距离阈值、地图边缘、非4整除尺寸、空数据、全部排除、全越界、NaN/Inf和形状错误等；另外验证15份V16既有三图方向矩阵和40组`corroborated_map()`像素结果。

比较返回类型、数组形状、dtype、逐字节内容、可写性及输入未被修改。此验证覆盖记录在EQUIVALENCE.json中的输入；不等于对任意外部畸形对象的形式化证明。测试进程主动阻止导入`swarm_rescue`。

使用同一服务器、同一Python 3.11.17、NumPy 1.26.4、OpenCV 4.11.0，两版固定在同一个预采样空闲的逻辑CPU 0 上交替执行；测试期间整机CPU忙碌率范围为22.65%～23.01%。这是受控的纯函数配对测试，不把它称为整机低负载的全场测试。墙钟和进程CPU时间分别记录，不使用单独两场墙钟差值推断性能。

稳态计时不包含导入。另行测得依赖已加载后的模块执行中位数：V16 1.24微秒，候选 656.76微秒，即查表带来约0.656毫秒的一次性初始化成本。

每次激光归并约节省0.20毫秒。不能把67%/76%的函数收益当作整场收益：整场还有导航、拟合、传感器、物理和绘制开销；本次没有测量整场节省秒数，也没有新的得分或探索率结果。相同输入下保持结果，实际运行加速仍可能改变原有墙钟阈值对应的步数。
