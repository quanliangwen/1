# 未见之变 · SHIFT LAB

一个面向论文课堂汇报的互动开场：**昨天验证表现良好的模型，遇到新的客户与预测关系后，还可靠吗？**

基于 Duan, Yang, Abbasi & Tam (2026), *Robust Predictive Modeling Under Unseen Data Distribution Shifts: A Methodological Commentary* 的方法论主张设计。

论文链接：<https://doi.org/10.1287/isre.2022.0537>

> 本项目是合成数据上的教学演示。它使用简化的有限情景 DRO，不是论文完整算法、数据或实证结果的复现。页面单独列示了原论文表 3、4 的数据。

## 快速使用

无第三方运行依赖，不需要 API Key、数据库、Python 或 GPU。计算全部在访问者浏览器内完成，不上传样本或实验选择。

### 直接离线打开

下载仓库 ZIP 并解压，双击 `index.html`。离线文件方式会在主线程训练；通过 HTTP 访问时默认使用 Web Worker。首次训练通常只需片刻，具体取决于设备。

### 本机网页预览

安装 Node.js 18 或更新版本后，在仓库目录运行：

```sh
npm start
```

浏览器打开 <http://127.0.0.1:4173>。无需先运行 `npm install`。默认只监听本机回环地址。

也可使用已有的 Python：

```sh
python -m http.server 4173 --bind 127.0.0.1
```

### GitHub Pages

本仓库可直接作为静态网页，无需构建。

1. 将代码推送至 `main`。
2. 打开仓库 **Settings → Pages**。
3. **Build and deployment → Source** 选择 **Deploy from a branch**。
4. 选择 `main` 与 `/ (root)`，保存，等待 GitHub Pages 部署完成。
5. 部署成功后，可访问 `https://quanliangwen.github.io/1/`。

该地址只有在 Pages 部署成功后才可用。`.nojekyll` 用于跳过 Jekyll 处理。所有网页资源使用相对路径，支持 `/1/` 子目录部署。

## 3–4 分钟开场流程

1. **部署之前**：选择训练防护范围，比较两种模型在独立同环境留出集上的 AUROC。
2. **做出判断**：冻结模型，请观众判断是否允许上线。此时不会显示新环境的结果。
3. **揭晓新环境**：选择“客户变了”“关系变了”或“同时变化”，观察样本分布、分类边界与性能曲线。
4. **检查边界**：打开“边界外冲击”，连之前稳定的活跃度关系也反转，再讨论保护假设。
5. 回到已有 PPT，介绍论文的正式方法与实证结论。

右上角 **投屏模式** 隐藏下方长文；左右方向键切换阶段，`Esc` 退出投屏。滑块拥有焦点时方向键保留为滑块操作。**导出本轮结果** 可保存模型权重、参数、随机种子与评价结果 JSON；尚未揭晓时导出不包含目标域分数。

**新一轮实验** 会解锁训练设置并更换评价随机种子。查看测试结果后再选参数属于探索，不能宣称是严格未见环境的最终验证。

## 计算方法

### 合成数据

- 特征 `x`：标准化客户活跃度。
- 特征 `z`：标准化促销接触度。
- 标签 `y=1`：流失。
- 基础条件规则：`P(y=1|x,z)=sigmoid(-1.5*x + b*z - 0.2)`。
- 三个源域的 `b` 为 `0.6, 1.2, 1.8`，每域 420 个样本。同环境留出集以 `b=1.2` 生成。
- 客户构成滑块 `c`：`x=u-0.85*c`，`z=v*(1+0.25*c)+0.75*c`，保持条件规则。
- 关系滑块 `k`：测试系数 `b=1.2-3.6*k`，保持输入样本。
- “边界外冲击”：另将活跃度系数从 `-1.5` 变为 `+1.5`，该机制未纳入训练情景。

训练与评价使用不同随机种子，同轮评价复用潜在随机数，减少比较中无关的抽样波动。所有评价指标使用 2,400 个模拟样本；散点图仅显示前 360 个。默认训练种子为 `615`，默认评价种子为 `20261026`，重开实验每轮评价种子增加 `1000`。

### 两种训练目标

两者均为带截距、两个特征的逻辑回归，L2 正则权重 `λ=0.012`，不惩罚截距。

- **ERM**：最小化三个源域的平均对数损失，加相同的 L2 正则。
- **情景 DRO**：在三个源域外，预设 9 个变化情景，近似最小化这 12 个有限情景的最大对数损失。

训练防护范围 `r∈[0,1]` 确定扩展情景：

```text
b ∈ {0.6 - 2.8*r, 1.2, 1.8 + 0.6*r}
c ∈ {-0.75*r, 0, 0.75*r}
```

取笛卡尔积组成 9 个变化情景，均在揭晓测试环境前构造，不访问目标域。

为得到稳定、可在浏览器中快速运行的优化过程，使用平滑最大值：

```text
minimize θ: τ * log(sum_s exp(R_s(θ) / τ)) + λ*||w||²/2
```

`τ=0.02`。数值实现使用 log-sum-exp 技巧避免溢出。平滑最大值位于 `max_s R_s` 与 `max_s R_s + τ*log(12)` 之间。梯度下降 620 次，学习率为 `0.8/(1+0.003*iteration)`。

**它不是论文中通过跨域辅助模型、协变量与概念偏移双约束定义的不确定集。** 方法选择旨在让教学机制清晰且可复查。教学中原环境表现可能下降，不意味着原论文报告同样的结果。

### 评价

- AUROC 由预测分数的秩统计计算，采用并列分数平均秩。
- 同时计算对数损失与分类准确率，详细结果随 JSON 导出。
- 曲线：固定当前客户构成，在 17 个概念偏移强度上评价。
- 网格：`c,k∈{0,0.33,0.67,1}`，共 16 个情景，显示网格最低 AUROC。
- 训练优化对数损失，不直接优化 AUROC。网格最低 AUROC 不是对所有未来分布的最坏风险保证。
- 图中范围阴影仅表示有限训练情景的参数包络，不构成对其内部连续分布的性能证明。

程序没有预设 DRO 在所有情景下获胜。

```sh

```
